📌 وصف المشروع

موقع بورتفوليو شخصي يعرض: نبذة تعريفية، المهارات، الخبرات، المشاريع، المقالات، وقسم للتواصل.
الموقع مبني باستخدام HTML, CSS, JavaScript مع هيكلة منظمة للملفات (CSS وJS داخل src/، الصور داخل public/images/).
المحتوى يتم تحميله ديناميكيًا داخل <main id="app"> عبر توجيه بسيط بالـ hash routing.
________________

🔄 الفروقات بين النسخة الأصلية والنسخة المحدثة

✅ تنظيم الكود: تقسيم الأقسام داخل ui.js إلى دوال مستقلة (renderHero, renderAbout, renderSkills, …).

✅ إضافة قسم الخبرات (Timeline) بشكل واضح.

✅ تصحيح مسارات الصور → جميع الصور انتقلت إلى public/images واستخدام مسارات صحيحة.

✅ app.js: لم يتم حذف أي منطق قديم → فقط تم تحديث جزء عرض المحتوى ليستدعي الدوال من ui.js.

✅ index.html: بقي كما هو تقريبًا (الهيدر، الفوتر، main container).

جعل المشروع أكثر تنظيمًا وسهولة في التوسع.

فصل منطق عرض الواجهة (UI) عن منطق التطبيق (app.js).

الحفاظ على جميع المميزات الأصلية بدون أي حذف.
