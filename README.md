
# 📘 ملاحظات الإصدار (نسخة v2)

> **هدف الملف**: توثيق كل التغييرات التي تمت للحصول على النسخة الثانية المرفقة، بشكل مبسط وسهل.

## ✅ ملخص سريع للتغييرات
- 🔥 **الموقع عربي فقط**: تمت إزالة أي دعم للإنجليزية (ملفات/أزرار/منطق الترجمة).
- 🖼️ **تنظيم الصور**: جميع الصور تحت `assets/images/` وتم تحديث المسارات داخل الأكواد والـ JSON.
- 🎨 **الألوان**: استبدال الأزرق بالكامل باللون الأساسي `#fff2c6` (للروابط والأزرار والهايلايت).
- 🧭 **القائمة**: إضافة صفحة **من أنا** وتوحيد المسارات: الرئيسية، من أنا، المشاريع، المقالات، تواصل.
- 🧱 **هيكل بيانات بسيط**: المحتوى يأتي من ملفات `data/*.json` بدون مجلد `lang/`.
- 🛠️ **تحسينات الواجهة**: بطاقات موحدة، صور بنسبة ثابتة، ونموذج تواصل محسّن وفق روح قالب Massively.
- 🚀 **تشغيل صحيح**: يعتمد على `fetch`، لذا يجب تشغيله عبر خادم محلي (Live Server) أو استضافة مثل Vercel.

---

## 🧭 هيكل مجلدات النسخة الحالية (v2)
(انظر إلى بنية المشروع داخل المجلد المرفق؛ جميع الصور تحت `assets/images/` وجميع ملفات البيانات تحت `data/`).

---

## 🖼️ مقاسات/نِسَب الصور المقترحة
- **صورة الـ Hero**: مستعرضة كبيرة (يفضّل 1600×800 أو 1600×700) → `assets/images/hero.jpg`
- **الصورة الشخصية**: مربّعة 1:1 (مثلاً 800×800) → `assets/images/profile.jpg`
- **صور المشاريع**: نسبة 4:3 (مثل 1200×900 أو 800×600) → `assets/images/projects/*`
- **صور المقالات**: نفس 4:3 لمواءمة البطاقات → `assets/images/articles/*`

> استخدم أسماء ملفات واضحة (بدون مسافات) وحروف لاتينية لتفادي مشاكل الروابط.

---

## ▶️ كيفية التشغيل محليًا
لأن الصفحات تقرأ JSON باستخدام `fetch`، فتح الملف مباشرةً لن يعمل على بعض المتصفحات.
- **VS Code**: شغّل إضافة **Live Server** ثم افتح `index.html` عبرها.
- **بديل**: ارفع المشروع على Vercel/Netlify/أي استضافة تدعم ملفات ثابتة.

---

## ✏️ كيف تعدّل المحتوى بسهولة
- المعلومات الأساسية: **`data/profile.json`**
- السيرة والتقسيمات: **`data/about.json`**
- المهارات: **`data/skills.json`**
- المشاريع: **`data/projects.json`** (ضع مسارات الصور تحت `assets/images/projects/`)
- المقالات: **`data/articles.json`**

بعد الحفظ، حدّث الصفحة (أو سيحدّث تلقائيًا لو تستخدم Live Server).
